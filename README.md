# M626 Software System Architectures - Lab Repository

Welcome to the official lab repository for the **M626 Software System Architectures** module.

This repository contains all the hands-on lab exercises, design tasks, and practical activities that support the weekly lectures of the module.

---

## About the Module

This module introduces fundamental and advanced concepts of software system architecture and architectural design principles for complex software systems. It explores architectural styles, design patterns, quality attributes, and evaluation techniques relevant to large scale and distributed software systems.

**Module Code:** M626
**Credits:** 5 ECTS
**Workload:** 125 Hours (50 Contact + 75 Self Study)
**Level:** Master
**Module Teacher:** Dr. Nasir Mehmood Minhas
