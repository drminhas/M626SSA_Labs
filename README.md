# M626 Software System Architectures - Lab Repository

Welcome to the official lab repository for the **M626 Software System Architectures** module.

This repository contains all the hands-on lab exercises, design tasks, and practical activities that support the weekly lectures of the module.

---

## About the Module

This module introduces fundamental and advanced concepts of software system architecture and architectural design principles for complex software systems. It explores architectural styles, design patterns, quality attributes, and evaluation techniques relevant to large scale and distributed software systems.

**Module Code:** M626
**Credits:** 5 ECTS
**Workload:** 125 Hours (50 Contact + 75 Self Study)
**Level:** Master
**Module Teacher:** Dr. Nasir Mehmood Minhas

## How to Use This Repository

1. Open the folder for the current week.
2. Read the `Lab-Instructions.md` file inside that folder.
3. Complete the task as described.
4. Create a new folder with your name inside the week folder, for example `John-Doe-Week1`.
5. Upload your completed work into your personal folder.
6. Commit and push your changes before the end of the week.

**Important:** The weekly labs are practice activities and are not graded directly. However, they are mandatory. You must submit them on time because they create the exact diagrams and documents you will need for your 70% Final Project. 

---

## Submission Format

Unless stated otherwise in a specific lab, please submit your work in one of the following formats:

- Diagrams: PNG, JPG, PDF, or draw.io files
- Text explanations: Markdown (.md) or plain text (.txt) files
- Architecture Decision Records: Markdown files following the ADR template
- Code or configuration files: Only when the lab explicitly requires them
