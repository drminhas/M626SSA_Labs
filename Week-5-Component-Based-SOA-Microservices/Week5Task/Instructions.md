# Week 5 Lab: Microservice Decomposition

## The Scenario
You are given a description of a monolithic online bookstore that handles user accounts, book catalogues, shopping carts, payments, and inventory all in one codebase.

## Your Task
Decompose this monolith into logical microservices. Draw the service boundaries and decide how the services will communicate with each other.
