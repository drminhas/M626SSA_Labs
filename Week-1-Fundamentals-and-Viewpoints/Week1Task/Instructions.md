# Week 1 Lab: Viewpoint Sketching

## The Scenario
Imagine you are designing a new mobile application for ordering food delivery.

## Your Task
Draw this exact same system from two different architectural viewpoints.
1. The Developer Viewpoint: Draw how the software is structured. Include the mobile app, the backend server, and the database.
2. The Security Engineer Viewpoint: Draw the same system but focus on data protection. Show where passwords and payment details are stored and draw a secure boundary around them.
